# Grammar Game for Grade 10, 11 & 12
By Teacher Nolie. Learn. Practice. Compete.

## Files (Phase 1)

| File | What it does |
|---|---|
| `index.html` | Home page with the branding |
| `setup-check.html` | Tests that Firebase is connected correctly |
| `css/style.css` | The look of the whole app (navy theme) |
| `js/firebase-config.js` | **The only file you edit**: your Firebase settings |
| `js/setup-check.js` | The code behind the setup check page |
| `database.rules.json` | Security rules to paste into Firebase |

## Rules of the project
- Only `js/firebase-config.js` needs your settings. They are not secret.
- Never add a Firebase "admin" or "service account" key to these files.
- Open the app from GitHub Pages (https://...), not by double-clicking the files.
  Browsers block the Firebase code when a page is opened from your computer's disk.
