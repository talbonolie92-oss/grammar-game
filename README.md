# assets

Put your school logo in this folder with exactly this file name:

    school-logo.png

Tips:
- Use a PNG, ideally with a transparent background.
- A square or nearly square image works best (for example 400 x 400 pixels).
- The name must be all lowercase: `school-logo.png`.

Until the file exists, the website shows a small neutral "Logo" placeholder.
As soon as the file is uploaded, the logo appears automatically on every page.
